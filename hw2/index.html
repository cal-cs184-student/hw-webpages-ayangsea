Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Causteljau's algorithm is an algorithm that allows us to create an N degree bezier curve from a list of N + 1 control points. It does this recursively. In each step, each pair of adjacent K points are linearly interpolated along with a parameter t to evaluate K - 1 intermediate points, until only one point remains, which will be the point on the actual bezier curve. To implement my evaluateStep() function, I iterated i from 0 to points.size() - 1, and in each step, I took the points at index i and index i + 1. To calculate the intermediate points, i used the formula p_i' = (1 - t) * p_i + t * p_i+1 to calculate the x and y, and added it to my output list.
